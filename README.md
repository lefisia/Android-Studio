## 📂 Meus Projetos

### 1. Pincel MultiTouch
**Diretório:** [`/Pincel_MultiTouch`](./Pincel_MultiTouch)

Um projeto focado na experimentação e processamento de mecânicas de toque simultâneo no ecrã do dispositivo móvel.
* **Tecnologias:** Android SDK, manipulação de *Canvas*.
* **Conceitos:** *Multitouch gestures*, processamento de eventos de *hardware*, renderização gráfica nativa.
* **Competências Desenvolvidas:**
  * Estruturação da arquitetura base do projeto no Android Studio via Gradle.
  * Compreensão e captura de múltiplos eventos de ecrã tátil (Pointer IDs, coordenadas simultâneas).
  * Design de sistemas responsivos a interações complexas do utilizador (fundamentais para controlos de jogos *mobile*).

### 2. Simulador RPG
**Diretório:** [`/Simulador_RPG`](./Simulador_RPG)

Construção das lógicas de UI/UX e sistemas centrais típicos de *Role-Playing Games* adaptados ao paradigma de telemóvel.
* **Tecnologias:** Android Studio, XML (Layouts).
* **Conceitos:** Arquitetura de interfaces dinâmicas, gestão de estado, *Views* e *ViewGroups*.
* **Competências Desenvolvidas:**
  * Configuração do ambiente de desenvolvimento e organização hierárquica do projeto Android
  * Tradução de mecânicas clássicas de RPG (como atributos, inventários e menus) para *layouts* responsivos através de ficheiros XML.
  * Planeamento de arquitetura de software voltada para a escalabilidade das regras de negócio do jogo.
